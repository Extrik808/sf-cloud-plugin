# SF Cloud

Salesforce development plugin for WebStorm and other JetBrains IDEs (2026.1+). It wraps the Salesforce CLI (`sf`) and Salesforce's own language servers, and adds the IDE UI on top.

## Install

Takes about two minutes. You need WebStorm (or another JetBrains IDE) **2026.1 or newer** and the Salesforce CLI (`sf`).

**1. Download the plugin file**

Open **[Releases → v0.1.0](https://github.com/Extrik808/sf-cloud-plugin/releases/tag/v0.1.0)** (you must be signed in to GitHub — the repository is private) and under **Assets** click **`sf-cloud-plugin-0.1.0.zip`**. Keep it as a zip — do not unpack it.

**2. Turn off Illuminated Cloud 2** — skip this step if you never installed it

**Settings** (Cmd+, on macOS, Ctrl+Alt+S on Windows/Linux) → **Plugins** → **Installed** tab → find **Illuminated Cloud 2** → untick it. The two plugins cannot work at the same time.

**3. Install the zip**

Still in **Settings → Plugins**, click the **⚙ gear** at the top → **Install Plugin from Disk…** → choose the downloaded `sf-cloud-plugin-0.1.0.zip` → **OK**.

**4. Restart the IDE**

Click **Restart IDE** when it asks.

**5. Pick your org**

Open your Salesforce project. In the **bottom-right corner** of the window (status bar) click the connection widget and choose an org. That's it — the first time, SF Cloud downloads the Apex language server and builds the Apex/SObject index for completion by itself; this takes a minute or two.

### Updating to a new version

Download the new zip and repeat steps 3 and 4. The old version is replaced automatically.

### Something went wrong?

| Problem                                           | Fix                                                                                                |
| ------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| The release page shows **404**                    | You are not signed in to GitHub with the account that has access to this private repository        |
| **"Plugin is incompatible"** on install           | The IDE is older than 2026.1 — update it (**Help → Check for Updates**)                            |
| `.cls` files open with the wrong highlighting     | Illuminated Cloud 2 is still enabled — do step 2 and restart                                       |
| No orgs in the status bar widget                  | The Salesforce CLI is not found — install `sf`, or set its path in **Settings → Tools → SF Cloud** |
| No completion for `Account.`, `String.` and so on | Run **Tools → SF Cloud → Generate Offline Symbol Table** once the org is selected                  |
| LWC completion does not start                     | Node.js and npm are missing — they are needed only for the LWC language server                     |

## Language servers

On the first Apex file the Apex language server is downloaded, on the first LWC file the npm package is installed. Both are also under **Tools | SF Cloud** and in **Settings | Languages & Frameworks | SF Cloud | Apex**.

The LWC language server parses `CustomLabels.labels-meta.xml` and the `staticresources`, `contentassets` and `messageChannels` `-meta.xml` files as strict XML and exits when one of them is malformed (an unescaped `&`, for example). SF Cloud checks those files when it starts the server and names the offending file; SF Cloud's own LWC completion keeps working either way.

## Development

### Build the plugin from source

```sh
git clone https://github.com/Extrik808/sf-cloud-plugin.git
cd sf-cloud-plugin
./gradlew buildPlugin
```

The zip lands in `build/distributions/sf-cloud-plugin-<version>.zip`; install it as in step 3 of [Install](#install).

Before the first build, adjust `gradle.properties` to your machine:

| Property                                                      | Points at                                                                                                              |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `platformPath`                                                | The IDE install the plugin compiles against, e.g. `/Applications/WebStorm.app` or `/Applications/IntelliJ IDEA.app`    |
| `org.gradle.java.home`, `org.gradle.java.installations.paths` | The JetBrains Runtime bundled with that IDE: `<platformPath>/Contents/jbr/Contents/Home` on macOS                      |
| `aiAssistantPath` (optional)                                  | The AI Assistant plugin directory; defaults to `~/Library/Application Support/JetBrains/WebStorm2026.1/plugins/ml-llm` |

### Tasks

```sh
./gradlew test          # lexer, PSI, run configuration, CLI output parsing
./gradlew verifyPlugin  # JetBrains Plugin Verifier against the local IDE
./gradlew runIde        # sandbox IDE with the plugin
```

Feature gaps against Illuminated Cloud 2 are tracked in [docs/ic2-gap-analysis.md](docs/ic2-gap-analysis.md).

## Layout

| Package    | Responsibility                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------- |
| `api`      | REST and SOAP client on top of `sf org display` sessions, anonymous Apex over the Apex SOAP API           |
| `core`     | `sf` process runner and JSON helpers, sfdx project model, notifications                                   |
| `settings` | Application, project and tool window settings, settings page                                              |
| `org`      | Org list, connection combo and status bar widget, org actions                                             |
| `lang`     | Apex, SOQL and SOSL languages, lexer, highlighting, structure view, reference resolution and usage search |
| `editor`   | Bundle file tabs below the editor                                                                         |
| `lsp`      | Apex and LWC language server integration and installers                                                   |
| `metadata` | Org metadata listing and cache, scope dialog, retrieve / deploy / delete / compare operations and actions |
| `deploy`   | Deploy service, deploy on save, inline problems, Problems tool window                                     |
| `tests`    | Apex Unit Tests run configuration, runner, locator, gutter icons, coverage                                |
| `log`      | Debug log parser, language, Log Analyzer tool window, log levels, trace flags and debug levels            |
| `repl`     | Anonymous Apex, SOQL Query and SOSL Query tool windows                                                    |
| `ui`       | Shared tool window, toolbar and notification helpers                                                      |
